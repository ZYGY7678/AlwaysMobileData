נתונים תמיד פעילים — Android 4.4.4 ומעלה

האפליקציה מפעילה בדיקה כל 30 שניות ומריצה svc data enable דרך su, וכן מתחילה לאחר אתחול.
נדרשת הרשאת Root ומנהל SU צריך לאשר אותה. הצלחת הפקודה אינה מבטיחה קליטה או אינטרנט; אין עקיפה של חסימת SIM, חבילת גלישה, מצב טיסה או מגבלות מפעיל.

פתיחה ב-Android Studio. GitHub Actions בונה APK מסוג debug ומפרסם אותו כ-artifact.
